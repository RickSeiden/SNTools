# Privacy Policy for SNPlugins

**Last Updated:** November 27, 2026

This Privacy Policy explains how the **SNPlugins** browser extension ("SNPlugins", "the extension", "we", "us", or "our") handles information when you use the extension.

## 1. Data Stored by the Extension
- SNPlugins does not store any data other than the plugins you write, create, import, or configure (such as plugin names, match patterns, active/library flags, and JavaScript or CSS code) along with the extension's enabled setting.
- All stored plugin configurations and settings are saved locally in your browser using `chrome.storage.local`.

## 2. Local-Only Storage and No Server Transmission
- SNPlugins stores your scripts and plugin data strictly locally in your browser.
- The extension does not send, transmit, or upload any data to any external server.

## 3. No Access to Personal Information
- We do not have access to any personal information, including names, web activity, banking information, or any other personally identifiable information (PII).
- While your scripts and helper utilities execute locally in your browser on matching ServiceNow pages to provide the functionality you configure, we do not collect or receive any personal information or page data.

## 4. No Request for Personal Information
- We do not want access to any personal information—such as names, web activity, banking information, or any other personally identifiable information—and we will never ask for them.

## 5. Commitment Never to Sell User Information
- Because we do not have access to any personal information, we cannot sell it.
- We do, however, promise never to sell any information about any user to anyone, ever.

## 6. GitHub Comments and Issues
- If a user chooses to leave a comment or issue on GitHub related to SNPlugins, we will only use that comment or issue to improve or fix the extension.
- Nothing entered on GitHub will ever be shared outside of the comment or issue, and we will not sell any information entered into a comment or issue in GitHub.

## 7. Updates to This Privacy Policy
- If this Privacy Policy is updated in the future, the "Last Updated" date at the top of this document will be revised.
